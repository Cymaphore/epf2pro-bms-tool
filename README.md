## BMS Analysis of ePowerFun ePF-2 PRO 653Wh

This script and protocol spec is the result of reverse engineering the proprietary battery protocol
of the "ePowerFun ePF-2 PRO 653Wh" battery (type FM-1304-3400-RS1 according to the label).

It was obtained using PicoScope and a CP2102 and analysis of the raw data, so there is
absolutely no guarantee about it being correct

Batteries pose inherent risks (fire, explosion, etc.). Use this information at your
own risk. Some of the information is currently speculative and must be validated.

Script only tested under GNU/Linux.

My personal goal is to include BMS-internal information in my own personal capacity and battery tests.
